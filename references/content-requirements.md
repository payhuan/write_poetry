# 典故与必含片段

输入解析增加两个可选数组，存放在 request 下。不提供时按空数组理解，旧 0.3.0 状态不注入新字段，避免改变旧结果的上下文摘要。所有新要求参与既有 request 上下文绑定。

## 提取格式

用户原文：“写一首秋诗，用庄周梦蝶的典故，要包含山寺秋深落叶多”。提取示例：

```json
{
  "theme": "秋",
  "allusions": [
    {"id": "a1", "name": "庄周梦蝶", "description": "", "required": true, "source_excerpt": "用庄周梦蝶的典故"}
  ],
  "required_fragments": [
    {"id": "f1", "text": "山寺秋深落叶多", "kind": "line", "mode": "exact", "line_index": null, "source_excerpt": "要包含山寺秋深落叶多"}
  ]
}
```

allusions：id、name、source_excerpt 必填；description 默认空字符串，仅记录用户解释，不编造典故出处或释义；required 默认 true，用户明确说可选才填 false。典故名称可根据用户说明概括，但 source_excerpt 必须来自原文。解析完成后按 [典故查询与规范化](allusion-lookup.md) 建立独立引用；不把规范主典名写回用户 request。名称精确对应多条记录且会影响创作时须消歧。不要用是否出现典故名称来判定成功用典；语义确认属于后续 LLM 流程。

required_fragments：id、text、kind、source_excerpt 必填。text 必须逐字来自 source_excerpt，不替用户炼字或转换简繁。kind 为 line（完整诗句）或 phrase（连续短语）；mode 默认 exact：

- exact：用户说“包含”“原句保留”“不能改字”。原字顺序必须保留，不能同义替换。外围格式标点可按既有规范化规则处理，原文仍完整保存。
- adapt：用户明确允许改字或润色。text 仍保存原文，后续由 LLM 检查是否保留主要意思。
- inspiration：用户说“以此为灵感”等，不要求逐字出现，不分配固定句位。

line_index 默认 null，指定时为从 1 开始的句号。多句原文拆成多个记录，保留各自原文依据；无法确定拆分或保留方式时澄清。单个数组内 id 必须唯一。

## 当前验证边界

程序验证结构、原文依据、片段原文、显式布尔值及句位类型。exact 的完整句字数须符合已选诗体；短语不得长于一句；非汉字和多句片段提示澄清。同一句位锁定不同完整句、短语不在该位置已锁定句中，以及不同完整句数量超过全诗容量时提示冲突。不修改原句，不自动放宽诗格，也不把原句提前写入 lines。

未指定诗体仍沿用默认七律，若因此与五字固定句冲突，会澄清诗体或保留方式；不会擅自将完整句改成短语。格式错误为 ValueError，明确内容冲突在解析入口为 ClarificationRequired（CLI 退出码 3）。

解析通过不表示平仄、押韵或用典已验证。当前不求解多短语排布、所有位置组合和格律可行性；由 Day 3 规划和后续全诗审校处理。仅有原句作为灵感但无主题时，LLM 可概括主题并将其标作未直接引用的推断。

## Day 3 消费约定

通过 request.get('allusions', []) 和 request.get('required_fragments', []) 获取要求。生成上下文必须携带这两个数组；模板、句位、原文与模式不可丢失。

exact 片段的满足性是确定性内容约束，独立于纯规则格律引擎。指定位置的完整句应锁定；未指定位置的片段先由规划安排，不能要求每一个候选都包含全诗所有片段。未轮到的要求标 pending；本句应履行却缺失的 exact 要求才阻断该候选。

典故、adapt 和 inspiration 由 LLM 处理语义，不作为虚假的程序格律检查项。必须用典的要求需要明确履行状态，不能只靠平均文学分掩盖遗漏。全诗完成后统一核对必含内容与必用典故。

与字数、平仄或韵部明确冲突时报告原因，unknown 时保留不确定，不擅自选择有利读音或改原句。用户修改要求后重新解析创建状态，废弃旧批次，不直接改 request 绕过上下文绑定。

上述消费约定已接入 Day 3，接口、内容计划、LLM 语义评价 JSON、履行结果失效和全诗审校边界见 [内容安排与履行](round-content.md)。输入解析代码保持原职责，未新增格律或典故语义判断。

Day 5 [全诗审校与润色](poetry-polish.md) 固定 Day 4 的内容安排，逐个修改包复检全部正文的 exact，并在完整新上下文逐句重新请求用典、adapt 等语义复核；即便改动不在承担句也不能沿用原稿语义结论。最终出口再次检查当前正文内容。诗题不进入这些检查，不能满足正文的必含片段。
