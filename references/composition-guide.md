# 创作规划

选取少量相互关联的意象，规划场景到情绪的推进，不要求每句重复主题词。绝句按四句规划，律诗按首联、颔联、颈联、尾联规划；律诗按起承转合规划四联，颈联须在承接中产生方向变化；不限定为换景。绝句按自身语义推进规划，不强加固定标签。

先形成语义完整、措辞自然的句或联，再针对动词、核心意象和韵脚炼字。文学排序关注主题契合、语言自然、意象层次、结构推进和关键表达，文学高分不能覆盖已知硬约束失败。

全诗审校关注视角、时间、情绪是否一致，意象是否重复堆砌，律诗中间两联的句法和意义对应，以及结尾能否收束。修改后重新校验。

单轮生成与评价使用 [候选与文学评分契约](poetry-round.md)。只向文学评价提交规则已通过的完整候选句；语言自然与主题契合各占 25%，意象表现占 20%，衔接与表达各占 15%。这些分数只用于本批次候选比较，不能替代规则检测、全诗判断或实际采用决定。不因华丽、生僻或机械增加“诗眼”而加分。
