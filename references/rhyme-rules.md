# 韵律资源

`data/rhyme/Pingshui_Rhyme.json` 是用户在 2026-09-18 提供并要求采用的扩充生僻字重新抓取文件。文件复制到项目内后统一为 UTF-8 和 LF 换行，运行时不依赖项目目录外路径，也不联网。`source.json` 保存当前文件 SHA-256、记录统计及已知来源边界；由于交付时没有附带源 URL、抓取时间、抓取程序或再分发许可，这些信息明确记为未知。

## 数据与接口

韵表结构是“声部 → 韵部 → 记录数组”：

```json
{
  "上平声部": {
    "一东": [
      {"char": "风", "senses": []},
      {"char": "中", "senses": []}
    ]
  }
}
```

每条记录只允许 `char` 和 `senses`。char 是一个 Unicode 码点；senses 是该字在这一声部／韵部归属下的来源释义。当前文件含 106 部、18032 条记录、13930 个不同字符，其中 3233 字有多个归属，765 条记录带 senses。相较上一版没有移除字符，新增 8399 个不同字符，主要扩充生僻字。

数据没有独立拼音字段。程序由声部推导平仄，并将 section、group、tone、senses 作为读音义项提供给 AI；不得虚构现代拼音。senses 为空表示来源未给释义，不能据此断言任意归属都适合当前语境。

`RhymeLexicon(data)` 兼容旧测试用字符串数组。`lookup(char)` 返回 section/group/tone；`lookup(char, include_senses=True)` 额外返回 senses。`resolve(char, reading)` 只接受已收录的 section/group 选择器。多归属字的 AI 判读和规则复检契约见[检测引擎](constraint-engine.md)。

## 数据边界

声部固定为上平声部、下平声部、上声部、去声部、入声部。简繁不自动转换，不接入词林正韵、新韵或现代汉语声调。韵部齐全只表示文件内有 106 个分组，不表示历代所有字形和读音均已收录。

`source.json` 的摘要用于阻止资源被无声替换。若以后重新抓取，应先把新文件复制到项目内，再更新摘要、统计、来源信息、测试和本文；不要让运行时代码读取项目外文件。
