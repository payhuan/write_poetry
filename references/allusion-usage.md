# 用典规范

用典用于以少量诗语调用较大的历史、文学或文化语义结构，并让原典与当前诗境发生可解释的映射。仅有主题词、人物名、器物名或一个相似意象，不构成合格用典。用典至少应提供语义压缩或诗意增益；两者皆无时，直接表达通常更合适。

本规范用于评价用户要求的典故，也约束模型自行提出的典故。用户明确要求用典时不能以“无典更好”为由删除要求；可选或模型主动提出的典故必须与无典表达比较，没有增益便不采用。

## 先建诗境，再选典故

不要从单个主题词直接搜索典故。检索前先从已有 request、全诗规划和当前正文整理：

- 说话者及身份；
- 场景、事件和时间关系；
- 核心与次要情绪及其方向；
- 希望直露还是含蓄；
- 当前需要表达的几个语义单元。

选典时比较原典和诗境的语义、情境结构、情感方向、人物身份与表达功能。前三项严重不合直接拒绝，不能用总分补偿。

## 独立分类维度

分类不是一个互斥枚举。内容评价分别记录：

- `source_type`：`event` 事典、`phrase` 语典、`unknown`；
- `visibility`：`explicit` 明用、`implicit` 暗用、`unknown`；
- `semantic_relation`：`direct` 正用、`inverse` 反用、`borrowed` 借用、`adaptive` 活用、`unknown`；
- `transformation`：`quotation` 直接引用、`rewrite` 改写、`allusive_transform` 化用、`unknown`。

暗用必须保留可解释的事件结构、语义关系、关键意象或语言结构，不能只删掉典名。化用必须重组原典意义与新诗境，不能只是同义换字。反用必须引用当前诗句中的反转、对照、讽意或假设信号；没有明确信号时，先按误义处理，不能把错误解释成反用。

## Gate 1：事实门

依照 `allusion_reference` 的出处和简释，分别判断：

- `persons`：人物是否正确；
- `relationships`：人物关系和行为主体是否正确；
- `event`：事件是否正确；
- `source`：出处是否可靠且没有张冠李戴；
- `core_meaning`：原义及当前采用的稳定后世义是否正确。

每项只能为 `pass`、`fail` 或 `unknown` 并说明理由。任何 `fail` 或 `unknown` 都不能得到 `satisfied`。真实人物、真实故事和真实意象拼成错误关系仍属事实错误。

本地 `resolved` 使用记录摘要绑定来源；`not_found` 若要判定通过，必须明确记录可靠外部来源。语料未收录、出处不足或互相冲突时保留 `unknown`。

## Gate 2：映射门

评价必须给出至少一条 `mapping`，明确“原典中的什么”对应“当前诗境中的什么”，并引用当前候选原文。随后逐项判断：

- `semantic`：核心意义匹配；
- `situation`：原典情境与当前事件存在结构对应；
- `emotion`：情感方向相合，或有明确对照设计；
- `identity`：人物身份、伦理关系和行动符合当前说话者；
- `function`：能说明它在此处承担何种表达功能。

五项都通过，且存在具体映射，才可能为 `satisfied`。“梦”对应梦蝶、“归”对应烂柯、“山水”对应桃源之类关键词触发属于表层匹配。

## 质量记录

通过两道门后再记录质量，不能用质量总分覆盖硬错误：

- `semantic_fit`、`context_fit`：各 0–4；
- `coherence`、`naturalness`、`semantic_gain`、`transformation`：各 0–3；
- 惩罚 `obtrusiveness`、`redundancy`：各 0–3；
- `total` 为以上正项之和减去惩罚项。

分数用于同批候选比较，不代表文学价值的绝对尺度。需要时可比较明用、暗用、化用版本；自然化用通常优先，但服从当前诗境，不设固定顺序。
判为 `satisfied` 时四项分类不能为 unknown，且 `semantic_fit`、`context_fit`、`semantic_gain` 必须大于零；这只是排除自相矛盾的报告，不设置统一的高分门槛。

## 错误代码

| 代码 | 名称 | 判定 |
|---|---|---|
| E01 | 错典 | 人物、关系、事件或出处事实错误 |
| E02 | 误义 | 核心典义或意义方向错误 |
| E03 | 表层匹配 | 只有词面相似，没有情境结构映射 |
| E04 | 硬塞 | 删除典故后表达反而明显自然 |
| E05 | 掉书袋 | 显式典名、人名过密 |
| E06 | 典义冲突 | 多个典故的表达方向缺少统一结构 |
| E07 | 重复用典 | 多个典故承担相同信息 |
| E08 | 伪化用 | 只换字，没有重构典义 |
| E09 | 过度晦涩 | 理解主旨必须连续破解冷僻典故 |
| E10 | 喧宾夺主 | 注意力从当前诗境转向典故本身 |
| E11 | 陈套 | 机械复现常见搭配，没有当前语境作用 |
| E12 | 无增益用典 | 没有提供直述之外的有效信息 |

事实、核心典义、语义或情境检查失败时，分别必须记录 E01、E02、E03。任何已识别错误都不能与 `satisfied` 并存。

## 全诗复检

Day 3 的判断只属于当前候选。Day 5 必须在完整正文中重新评价同一套事实、映射和质量字段，重点检查多个典故是否共同指向一个更高层意义，是否互相冲突、重复、过密或遮蔽主旨。正文任何改动都会使旧评价失效。

最终红线仍独立判断是否写反典故事实。事实或映射无法可靠确认时，内容要求保持 unknown，红线也不能通过；不得靠诗题、注释或事后解释修补正文中的错典。
